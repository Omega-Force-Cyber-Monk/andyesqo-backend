- (Claude) Secure uploads: files are no longer public static assets. `POST /uploads` detects the type from magic bytes (JPEG, PNG, WebP, HEIC/HEIF, PDF) and ignores the client's MIME type and filename, which prevents HTML or script uploads. Photo and document fields across inspections, damage reports, deliveries, fuel logs, incidents, compliance documents and avatars accept only stored-upload URLs. Covered by `test/uploads.e2e-spec.ts` and unit tests.
